# Real-cluster captures: kubeadm control plane on Ubuntu 24.04

Captured 2026-11-12 from a kubeadm v1.36.6 control plane (Ubuntu 24.04, crictl v1.36.0, node name `controlplane`), the setup the CKA exam uses. Commands marked "AS candidate" ran as the unprivileged user `candidate` without sudo; the manifests, `ls -l` and `crictl ps` at the end ran through sudo. `[exit N]` is the shell exit code. Content is verbatim except that the node's LAN address is replaced by 10.0.0.10; it holds file paths and flags only. Compare `real-cluster-captures-control-plane.md`, which came from kind.
